# Success Metrics (KPIs)

## North Star Metric
- **Simulation-to-Purchase Conversion Rate:** The percentage of users who utilized the "Smart Cart Simulation" or "Simulate Now" feature and subsequently completed a purchase.

## Product Engagement Metrics
- **Time in Simulation Lab:** Average minutes per session spent building or coding circuits.
- **Compile Success Rate:** Percentage of code runs that compile and execute without syntax errors.
- **AI Assistant Utilization:** Average number of prompts sent to "Electron" per active session.
- **Feature Adoption:** Percentage of users who use more than one core module (e.g., E-commerce + Simulation, or Simulation + PCB Design).

## Commercial Metrics
- **Monthly Recurring Revenue (MRR) / Gross Merchandise Value (GMV):** Total value of components, kits, and manufacturing orders processed.
- **Average Order Value (AOV):** With a goal to increase AOV via kit recommendations from the AI Assistant.
- **Cart Abandonment Rate:** Goal is < 40%, mitigated by the "Simulate Before Buying" confidence booster.

## Platform Health & Performance
- **Simulation Load Time:** Must be < 2 seconds for a standard kit.
- **Simulation FPS (Frames Per Second):** Must maintain minimum 60 FPS for 2D routing and 30 FPS for 3D viewing.
- **API Latency:** 95th percentile response time < 200ms.

## User Retention
- **W1 / W4 Retention Rate:** Percentage of users returning in Week 1 and Week 4, particularly targeting university students returning for recurring assignments.
